Простое Flutter-приложение для складского учета товаров.

## Что реализовано

- экран авторизации;
- экран регистрации;
- каталог товаров;
- карточка товара;
- базовая валидация всех полей;
- простая навигация между экранами;
- стилизованный интерфейс;
- разделение на UI, логику и данные.

## Структура проекта

- `lib/data` - модели и мок-репозитории;
- `lib/presentation/controllers` - состояние авторизации;
- `lib/presentation/screens` - экраны приложения;
- `lib/presentation/widgets` - переиспользуемые виджеты;
- `lib/app` - корневое приложение и тема.

## Как работает

1. Пользователь регистрируется.
2. Возвращается на экран входа.
3. После успешного входа открывается каталог товаров.
4. Из каталога можно перейти в карточку товара.

## Запуск

Если Flutter SDK еще не установлен или не добавлен в `PATH`, сначала настройте его.

Дальше:

```bash
flutter create .
flutter pub get
flutter run
```
